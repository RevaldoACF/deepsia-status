# Deepsia Status

Status page dan uptime monitoring untuk layanan **Deepsia** (`api.deepsia.my.id` dan `chat.deepsia.my.id`), ditenagai oleh [Upptime](https://upptime.js.org) melalui GitHub Actions.

<!--live-status-->

## Cara Mengubah Status Maintenance / Incident

1. **Otomatis (Down / Up):** Upptime memeriksa endpoint setiap 5 menit via GitHub Actions dan otomatis membuka/menutup GitHub Issue saat layanan down atau kembali normal.
2. **Manual (Maintenance):** Buka **GitHub Issue** baru di repository ini dengan label `maintenance` (sertakan nama layanan seperti `api` atau `chat` di judul/isi issue untuk menandai layanan terkait). Tutup issue setelah maintenance selesai.
